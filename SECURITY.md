# Security Policy

Shunshin Cam processes your webcam video locally. Nothing is uploaded. The only network
access is a one-time download of the MediaPipe models from Google's `storage.googleapis.com`.

## Reporting a vulnerability

Please **don't** open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/Ahmed8881/shunshin-cam/security/advisories/new)
instead. You can expect a reply within a week.
